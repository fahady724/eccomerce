# E Commerce Management System Using Java and SQLite

A desktop based E Commerce Management System developed using Java Swing and SQLite for the CSE205 Object Oriented Programming course.


# Requirements

Before running the project, ensure the following are installed:

- Java JDK 21 or later
- Java IDE (IntelliJ IDEA, Eclipse, NetBeans, or VS Code)
- SQLite JDBC Driver (`sqlite-jdbc.jar`)


# Setup Instructions

# 1. Clone the Repository

bash
git clone https://github.com/fahady724/eccomerce.git

or download the ZIP file and extract it.


# 2. Open the Project

Open the project using your preferred Java IDE.

Examples:

- IntelliJ IDEA
- Eclipse
- NetBeans
- Visual Studio Code


# 3. Add the SQLite JDBC Library

If your IDE does not automatically detect it:

- Locate `sqlite-jdbc.jar`
- Add it to the project's Build Path / Libraries


# 4. Verify Product Images

Ensure the following folder exists:

data/product_images/

This folder contains all product images displayed in the application.



# 5. Run the Application

Run:

Main.java

The application will start and open the storefront.
